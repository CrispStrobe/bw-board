# Bochs CPU3 Ring 3 reference source

Status: inactive source candidate. The `toolchain`, `build` and `reference`
producer flags and their three labeled workflow job guards are false. A source
claim and local pure controls authorize source review only. No Bochs compiler,
reference execution or guest result follows from this package.

The three routes have distinct requests, labels, jobs, units, originals and
readers. Each job must first authenticate the selected source checkout and the
executing workflow checkout. It then admits the exact owner event and canonical
request before any privileged service or selected tool input. The six named
steps for each route are checkout, workflow-source checkout, admission, pinned
Node cache preparation, bounded work and original retention. A complete job
requires the actual client and service outcomes, bounded raw streams, terminal
owned resources and an independently checked artifact. The bounded
`systemd-run --wait` completion receipt and sealed work original are retained;
a post-wait unit query may find an already unloaded successful unit. Unknown
service status stays unknown and cannot become an invented zero exit.

The Node toolcache is an input, not an execution proof. The source collector
copies it into one owned, read-only stage and rechecks identity before using
it. The selected compiler identity requires separate metadata admission. The
source, VGA binary and corresponding source notices must remain exact and
traceable. No fallback download, local package install or executable probe is
part of these source controls.

Proposed hosted envelopes are one CPU throughout: toolchain inventory 512 MiB,
no swap, 32 tasks and a five-minute job; standalone build 2 GiB, no swap, 64
tasks and a 20-minute job; reference capture 1 GiB, no swap, 64 tasks and a
ten-minute job. The finite child, outer, archive, stream and cleanup caps are
specified by the source request and reader. These budgets have not been
measured as sufficient. The runtime archive is acquired only after the sole
build original and official metadata are admitted; the reference job retains
its own nested archive for one independent read.

Run the source-only controls with `/usr/bin/python3 -I -B
scripts/i80386-bochs-ring3-reference/controls.py` and the wrapper with
`node --test test/i80386-bochs-ring3-reference.test.mjs`. Their mocked OS and
process edges establish neither a hosted build nor a fresh reference result.
The unchanged authored ROM and exact 1730-byte wire remain the acceptance
boundary; no strict 386DX, timing, RTx, whole-OS or release claim is made.

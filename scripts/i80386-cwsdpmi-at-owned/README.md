# Owned CWSDPMI AT code binding, source-only checkpoint

This is a bounded **unconnected** admission model for a later AT run of the [owned DJGPP client](../i80386-cwsdpmi-owned/README.md). It reads a newly linked MZ/COFF executable and linker map, checks the recorded owned client source, `-march=i386 -mtune=i386` commands, tool and source-archive pins, six resolved role admissions, executable/map hashes, and exact client `main` plus seven DPMI wrapper source ranges. The file layouts follow the [DJGPP MZ](https://www.delorie.com/djgpp/doc/exe/), [COFF header](https://www.delorie.com/djgpp/doc/coff/filhdr.html), and [section header](https://www.delorie.com/djgpp/doc/coff/scnhdr.html) descriptions. Receipt fields are model inputs: a future hosted gate must independently authenticate the receipt producer, complete source closure, toolchain bytes and implicit role resolution before this admission establishes actual provenance.

The returned layout is a diagnostic copy. Module-private copies of the linked `.text` and map roles are bound to the admitted layout object. `bindLoadedText` rejects a forged layout and compares those private bytes against a caller-supplied reader at the protected, 32-bit `main` entry. The reader is an obligation on the future CPU adapter: it must passively read ordinary guest RAM without changing paging accessed/dirty bits, MMIO latches, CPU state or board state. This source-only control does **not** establish that the AT loader actually placed those bytes there.

There is no interrupt observer, real-mode `INT 2Fh/AX=1687h` discovery, `main`→wrapper call proof, software `INT 31h` delivery/IRET frame proof, service order/handle continuity, AT guest run or performance result in this checkpoint. Those require separate source-backed hooks, copied session-bound tickets, full linked-code continuity, successful original delivery confirmation, stack and mode identity, bounded non-owned runtime classification, actual QEMU/AT same-media outcomes, and affected guest qualification. The CPU, client, compile and QEMU profiles are unchanged.

Run the bounded model control with `node scripts/i80386-cwsdpmi-at-owned/binding-control.mjs`. It checks MZ/COFF/map roles, wrong source/profile, altered loaded bytes, protected 32-bit entry, forged layout and mutation of public layout aliases. It neither compiles the client nor runs a guest.

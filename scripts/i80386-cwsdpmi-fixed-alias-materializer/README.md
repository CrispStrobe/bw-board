`da0dee52d70b47381f9673272411d5441530186d4f2c85fe18cf2e3d4063e08b`.

Exactly thirteen unique alias headers must appear. Each must have the fixed
canonical alias name, hardlink type, zero size and fixed safe canonical target.

selected-name aliases, nonzero hardlink bodies, wrong types, unknown or unsafe
targets, alias chains and forward targets refuse before preparation. Every
fixed target extent is checked before its body is read. Normal files cannot
occupy a fixed alias name, and fixed targets cannot be directories or links.

selected outputs retain exclusive creation, single-link ordinary metadata,

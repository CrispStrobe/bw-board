The policy allows only complete four-byte walker operations, correct PDE versus PTE kind, authenticated old/new values and actual raw physical address. It does not require that cached translations produce a walk or that backend callback order equals the JS tape.

The first native stack write sets the leaf's A and D together, `C003→C063`, only as a PTE-write kind 4 from the INT owner. A D update in IRET, instruction fetch, an unrelated entry or an intermediate `C003→C023` write is refused. Actual native walker chronology remains pending the first separately admitted guest.

Ordinary reads admit only the exact LGDT/LIDT ROM pointers, the owned GDT data/stack and code descriptor bytes, gate bytes 3180–3187 from INT, and the three IRET words in CFFA–CFFF. Every returned system value is checked. Three native frame writes must occur in source push order: FLAGS 0002 at CFFE, CS 0018 at CFFC, return IP 7005 at CFFA. Each is a two-byte ordinary write from attempt 18:7003/live 18:7005 at the exact successive stack-page generation 0/1/2, after the combined stack A/D update. No arbitrary stack write, error word, extra frame or handler host repair is admitted. Frame progress is committed only after the authentic host write returns with correct value, identity address, effect, generation, epoch and A20.

The new private provider reuses the held clock/lease/mapping/cache-publication machinery through an inverse-checked text derivative.

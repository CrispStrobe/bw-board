# Unarmed source-admission connection

This controller connects the existing exact source gate and bounded Git adapter,
the fixed six-input transport, and the fixed notice coordinator. It has no caller
URL, pin, factory, FD or command interface. External approval remains unset and
default execution refuses before filesystem, Git or network operations. This is
not an operational arming API or an actual provisioning profile.

The outside-commit approval binds the full declared source table and descriptor,
exact head and every bootstrap component byte. All declared executable and data
roles are verified before any component execution, including the fourteen frozen
inherited roles and coordinator dependencies. The running controller, interpreter
and operating system remain trusted. Source positions are finite Git/byte joins,
not a continuous lease or transitive closure proved merely by role kinds.

A fresh gate observes the complete profile before transport. Only then does the
controller privately bind a fresh transport's admission method to that same
before-position and lifecycle. Six fixed immutable authenticated bodies precede
one fixed coordinator call. An after-position and clean close observations are
required for reported completion. Full-profile snapshots remain separate from
explicitly derived fourteen-row inherited projections. All actual acquisition,
source ownership, lease, namespace, full-notice, legal, toolchain, compiler, guest
and performance flags remain false. No whole-process deadline is implemented.

The production completion predicate is copied from the reviewed finite full-tree
runner: 1196 ordinary files, 78 directory inventory rows, thirteen physical alias
observations and the selected five notices, with exact nested phases, flags,
counts and clean closes. The source-control harness uses tiny manufactured HTTP,
TAR/ZIP, notices and rows, and privately substitutes an exact tiny-fixture
predicate. Its completion is controller orchestration consistency, not actual
archive/readback/coordinator compatibility or a default full-tree result.

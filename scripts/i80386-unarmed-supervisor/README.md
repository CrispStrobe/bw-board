This source-only unit joins exact source admission, bounded Git observation, packet assembly and a fixed manufactured Python child. Actual acquisition always refuses before source loading or transport. An externally approved bootstrap map and descriptor seal remain unset by default; approval must stay outside the source commit to avoid a HEAD and digest cycle. The controls copy fourteen repository source files as metadata into tiny temporary Git repositories. Those programs are not executed. Fifteen supervisor controls cover before/after source observations, installed fixed child limits, raw output preservation, overflow, setup and timeout failures, first-error retention, reentry and immutable policy capture. Twenty-one admission controls use manufactured files and mocked Git facts.

Run these controls on Linux with Python and Git, from the repository root:

```sh
python -I -B scripts/i80386-unarmed-supervisor/controls.py
python -I -B scripts/i80386-unarmed-supervisor/gate-controls.py
```

Git operations have a separate 120-second aggregate budget. Disk preflight is an observation rather than a quota or sufficiency proof.

## Descriptor-cache and first-execution expectations

The genuine held Bochs CPU3 source from the stack build is the semantic reference, not an observation of paging execution. `bochs/cpu/access.cc` SHA `1ac261289fd31feded2b4e123f6aedf795277298e5adea946edabb94089bd526`, read checks at lines 127–170, ORs `SegAccessROK` for an ordinary readable segment with limit FFFF. Write checks at lines 82–102 OR both `SegAccessROK` and `SegAccessWOK` for writable type 3. `bochs/cpu/descriptor.h` lines 57–60 defines these bits as 2 and 4; this fixture never has the 4 GiB limit that adds the 8/16 fast bits. `bochs/cpu/access.h` SHA `c9f74122f4039120d26e21bf301f0ee03da6c4c80544627e6887557cdb537a65` lines 190–193 routes the word store through `agen_write`.

The future differential driver should therefore assert the DS descriptor row separately from represented-register parity: selector 0x10, index 2, TI/RPL 0, present 1, DPL 0, ordinary segment 1/type 3, base 0, limit FFFF, G/DB/AVL 0. The source-backed valid-bit expectation is 1 at the loaded/prefetch cuts, 3 after the first actual data read, and 7 after the actual write and readback. The selector index is not the valid field. No mask or permissive set should hide a mismatch; a real contrary observation must fail and be retained for source review. CS and other rows need their own source/phase assertions rather than borrowing DS bits.

The first native paging run remains separate and unqualified. It must retain all 166 native words while comparing every represented JS counterpart, full actual board state and seven physical 4096-byte pages at comparable ordinary instruction cuts. Physical code A000 and data B000 must differ from poisoned original aliases 7000/9000. Both backends must establish PDE/PTE accessed effects and data-leaf dirty on the write, with no code/PDE dirty effect. Native walker/operand/prefetch order and generation counts are recorded independently; neither the manufactured predicates nor the previous JS trace proves native callback chronology. No paging native total, parity result, full-OS capability or speed claim exists yet.

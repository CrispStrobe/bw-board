# Fresh CWSDPMI executable/map admission, without an AT guest

This profile is the next bounded step after the [source-only AT binding model](../i80386-cwsdpmi-at-owned/README.md). Its dedicated label-triggered hosted workflow checks out the exact own-repository PR head with read-only token permissions. It authenticates the complete inherited compile-helper directory, the dynamically imported archive reader, owned client and prior binding-model bytes against the reviewed base commit, then reruns the unchanged SHA-pinned DJGPP cross-compiler helper. The helper's tool, runtime, implicit-role, warning, object-format and MZ/COFF gates remain in force. Its source/archive/command report and newly produced executable and map must agree before the AT parser admits the linked `.text` span and eight client/wrapper map roles.

The executable, object, source archives and toolchain exist only in the hosted job's private work directory. The artifact contains bounded logs, source hashes, compiler report and map, independently decodable MZ/COFF header and section-table hex, input hashes, admission result or first-failure receipt, and a report inventory. It excludes linked code bytes and all executable, object, media and toolchain files. The raw header bytes allow an independent reader to check MZ/COFF offset and section arithmetic without trusting the parser's derived fields. A malformed or mismatched private map is refused before any admitted result; the original compile/helper failure remains visible in its reports.

This is **fresh format and map admission only**. It does not call `bindLoadedText`, inspect guest RAM, run QEMU or AT, observe protected entry, discover DPMI, or prove any `INT 31h` service or performance result. A later AT adapter must use a passive guest-memory reader and separately prove actual loaded-byte identity and software interrupt/IRET behavior. This workflow makes no adoption or general compatibility claim.

The pure controls are `node scripts/i80386-cwsdpmi-at-owned/binding-control.mjs` and `TMPDIR=<owned-scratch> node scripts/i80386-cwsdpmi-at-binding-actual/admit-control.mjs`. The latter tests bounded raw header capture, private-versus-retained map mismatch, symlink and missing-input failure receipts, and binary exclusion. They do not compile a client; a successful parser result requires the hosted fresh compile.

The first hosted parser result is recorded in [RESULTS.md](RESULTS.md) and its [selected receipt](RESULTS-RECEIPT.json). Tested source `f5f2996d0b049a5fe6e7c6a369b7ac315676beb6` reached fresh format/map admission. The later documentation commit did not rerun the compiler or execute an AT guest.

Exact baseline: compiled `f4a2f2ce`, runtime SHA `6fdf5fccf797777acce655be2609cf58fb498d18ad6d0dd78fdef8e38a505643`, copied-state NAPI SHA `8929ce31877a3f5a0617f56073c04ca2429bc55bb012b0929f38c24a04a637ab`. Frozen source, worker and artifacts remain immutable. New JS profile: `bw.cold-native.memory-clock-fusion.v1`. This requires a new addon/admission; an old ABI4 DSO is not admitted.

For nonempty MEMORY tape only, native preflight checks the original resume phase, count, independent ledger and absent pending mapping. Native transports an independent copied seven-word expected ledger, the copied bounded tape and exact physical request in one JS entry. The private source-owned composite runs unchanged clockTransfer (full tape preflight and actual board clock effects), checks the genuine seven-word reply BEFORE the unchanged read/write effect, then returns both actual replies. C retains the original seven-word validation and observed-byte/classification guards after return, clearing tape only after successful native validation. Native execution/reentry is forbidden throughout. Memory effects must not change clocks/mapping, as already required by the held board callback.

The equivalent fixed MEMORY/nonquery predicate checks dedicated ordinary fixed Uint32Array7; exact n/q/cycles/debt/deadline/epoch/A20; cycles=4+6q; deadline in 1..6000, debt<=deadline+5 and A20<=1. Native expected values are captured only after its unchanged ledger guards. JavaScript copies expectation before callbacks and validates a copied genuine reply before memory. This is an explicit authenticated JS trust seam in a separate profile: it cannot be replaced by an arbitrary supplied callback or user-selected expected ledger. C independently revalidates after return. No synthetic clock reply or normalized memory bytes are permitted.

`provider.mjs` implements the callback and complete pre-effect predicate draft. `runtime.mjs` and `napi.mjs` implement exact inverse derivatives; `bridge.inc` is their private transport helper. No preparer/build/admission integration exists yet. The original gate proposal was discarded: C→JS composite plus JS→C gate would retain two crossings. The chosen design removes the extra outer memory entry for eligible nonempty tape, without claiming a CPU benefit.

Non-MEMORY INIT/ENTRY/POSTPIO/PREPIO/PAGE/RETURN/ACK/fault/IRQ/HLT paths remain exact held source. Empty-tape memory uses its original single memory entry. A20/mapping, deadline, ownership, ordinary E16 pause and limits remain unchanged. C bookkeeping waits until return; on callback exception or mismatch the pending tape is not erased.

The provider captures independent expected-ledger and write-operand copies before clock effects, then returns the independently copied validated genuine clock reply rather than its callback alias. The native callback table and C ABI4 structs stay unchanged; a new private linked transport symbol and explicit export profile require separately authenticated generated source/DSO.

Record attempted outer clock entries separately by reason, fused outer entry attempts, and ordinary memory entry attempts; logical N/Q charges are not bridge-entry counts. Five proposed controls execute production-used JS predicate/composite, exact C preflight (mock effect), generated NAPI bridge syntax with declarations mocked, and exact full inverses. Mock syntax does not prove actual NAPI behavior or Bochs integration. Controls include: each wrong valid uint32 ledger word and boundary domain must refuse BEFORE write; valid clock-before-read/write order and bytes must hold; reentry, malformed buffers, aliasing, callback throw and observed-byte mismatch refuse. Exact inverse tests bind all untouched barriers and five-slot typed export. No build, guest, profiling or timing is authorized for this source stage.

Separate opt-in source profile only; not a native initializer, backend or AT-boot admission. The original compiled fe1/103, span110/116 and span CPU candidate stay unchanged.

The four files own a fixed repository-authored 64KiB self-test byte ROM, controller busy12/response32 cycles, a no-argument private provider and source controls. The source facade is exported for direct controlled denial tests, while the private factory accepts/exposes no caller board/config/hooks. A fresh actual controller is pinned before its first command; no in-flight response is reconfigured. Original actual read/write/PAGE operations, D1/OUT60 values1/3 and native clock tape/lease/preflight/mandatory POSTPIO protocol remain inherited/copied. Only AA/IN64/IN60 gain new guarded paths. Guards run after actual chip catchup and before device consumption; denied reads can still apply elapsed-time effects.

The compilerless ROM uses CLI and masks both PICs, issues exactly one AA, polls status at most64 times, stores55 and then emptyFF at592h/593h, emitsK and HLT; timeout/wrong data emitsF and HLT. The provider additionally requires both PIC masksff, no poll, no keyboard schedule, no keyboard/aux/foreign queue, no pending controller/keyboard command and only its owned delayed55 response. Status reads are inert at the controller, while machine catchup and deadline rearming remain real effects. Data reads consume55 once and then observeff once. Poll counts do not supply clocks.

Native integration is deliberately absent. A separate future C profile must pin this exact ROM hash and initializer/provider/profile identity, extend only byte OUT64AA and IN64/IN60 admission, retain preflush and mandatory post-PIO query even at zero debt, and define exact reset/HLT/wait/interrupt guards. The original native initializer hardpins the old ROM hash, marker, total/cut counts, faults/IRQ and execute pages; none are reused as qualification claims for this ROM. Fresh JS/native totals, checkpoints, full166-word snapshots, board/controller/PIC state, RAM/reset witness and complete native chronology must be measured and audited before any new native claim. General BIOS/AT/Windows/Doom execution remains outside this profile.

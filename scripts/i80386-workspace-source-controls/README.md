# Hosted standalone workspace source controls

This profile admits the exact own PR checkout and runs only manufactured Python
controls: phase9, route13, writer16 and creator15 methods. It never compiles a
client, imports a compiler helper, copies tools, launches a guest or runs Node.
The phase suite parses the disabled compiler as AST; it does not execute it.

Thirteen immutable unit paths are pinned to
`a3f4e0c2e6b5132bc91adb161365dcdc49213c5a`. Each Git blob hash must match its
fixed SHA-256; ordinary single-link bounded live files must equal those bytes.
The new three profile paths are also bound to exact Git/live bytes: sixteen
execution/source roles total. Git disables replacement objects on every call.
The nonexecuted lane claim is bound by exact HEAD and the closed change envelope;
no live LANES admission is required. Admission
requires exact primitive expected head, own repository and head repository,
pull-request event, attempt1, base ancestry and a closed new-profile/lane-claim
change envelope. Git subprocess output is capped at1 MiB and each invocation
has a10-second deadline. No source producer is imported by admission.

The known checkout/upload action commits and Ubuntu24.04 runner are pinned.
An exact PR/head concurrency group preserves an existing run without cancellation;
this is queue coordination, not a once-only runtime launch authority. Python
commands use isolated `-I -B` mode with Python path and loader injection variables
empty. This reduces ambient injection; runtime/source integrity remains an
external qualification gate. One automatic PR-only job has a five-minute bound,90-second admission bound and
30-second bound per suite. Core dumps are disabled. Shell file limits cap each
text output at at most64 KiB on the selected hosted Bash environment. The
artifact names exactly ten text roles: source JSON, eight suite stdout/stderr
logs and fixed terminal status. An admission failure preserves partial evidence
without inventing absent source JSON; it cannot qualify completed controls.
No binary, tool archive, client, RAM or private media is uploaded.

`SOURCE_CONTROLS_ONLY_NO_COMPILER_CPU_GUEST_OR_PERFORMANCE` means source-report
binding only. It grants no source-owned parent/workspace context, live source
instance, uninterrupted filesystem identity, compiler/guest result, frame return
or performance authority. The original-source reader must validate official
run/head/job/artifact identity, inventory, hashes and full suite transcripts;
all enabled exact-head checks remain required. No dispatch, label, replay or
actual execution profile is provided. Production compiler disable is unchanged.

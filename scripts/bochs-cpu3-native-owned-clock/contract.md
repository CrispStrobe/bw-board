# Experimental source-owned native ABI3 candidate

Implemented source derivatives and controls are not compiled or runtime admitted. Generic H4 ABI2 dynamic methods/getters and its main-thread loader are unchanged. New ABI3 is a separate loaded image and authenticated closure, not an ABI2 extension or caller ownership brand.

The factory admits primitive serialized artifact/configuration paths and SHA values for a trusted diagnostic harness. It accepts no board, ROM, hooks, callbacks, functions or nested live caller references. Those frozen harness artifacts and parent Node infrastructure are trusted; hashing a pathname is not a filesystem race defense. The worker builds the fixed source ROM and actual private board, keeps all clock/memory/PAGE/PIO/ACK callbacks local, and owns the initializing native thread. Parent IPC occurs only at resume/input/snapshot boundaries. No native buffer is exposed to callers.

Static 900-word storage preserves exact N1/Q0/QREP order through longjmp. Independent C entry and append caps constrain 600 N and 300 Q; total caps remain 160000/150000. Q adds six board cycles, and the ceiling horizon is based on actual chip debt/deadline. Mapping-pending rejects N and every observer before effects; ordinary Q alone is permitted until the original ordinary publication invalidates caches/TLB. Original native logical counters and BWSD1 rows remain at the original points. Physical transfers/commits/words have separate snapshot counters.

Every transfer has an exact attached ordinary Uint32Array7 response with cumulative N/Q, cycles, debt, deadline, epoch and A20. Clock commits check all values against the local mirror before clearing pending storage. INIT/ENTRY/POST_PIO zero-count queries have explicit native and private-provider phase guards. ENTRY can change actual debt/deadline through stageLine/beginRun only; POST_PIO can change them through the actual owned OUT catchup/rearm only. The source-owned provider reads and validates actual device state, while C checks phase, bounded domains, cumulative ledgers and expected mapping. C does not independently emulate PIT. Arbitrary raw addon callback providers are outside admission. Wrong tuples must fail closed, never be treated as evidence for arbitrary chip transitions.

Flushes precede memory, PAGE, PIO, ACK, fault, IRQ, HLT and returned snapshots. RETURN flush happens with JS lease, NAPI busy and native in_resume still active. Paused inspect/setIRQ/close assert empty pending tape. Capture-off removes optional journal writes only; logical clock effects, ordered tape, counts, caps, domains and guards remain.

The native globals retain a process-singleton terminal lifetime, initializing-thread/reentry/mutex guards and fatal abort behavior. The worker must run inside a bounded fresh child Node process for CLI/tests; Worker.terminate cannot safely interrupt arbitrary C++, and abort kills the whole process. The factory timeout is not native cancellation. This source candidate makes no browser GUI, production integration, legal-span count or speed claim. No actual native build/guest/benchmark is authorized by this document.

Validation gates remain source/inverse/syntax and hostile controls, then separately authorized compiled build, actual controls, full canonical CPU rows plus expanded bf12 journal/checkpoints/full RAM/PIT/PIC parity, and one predeclared unprofiled process-CPU gate. Diagnostic snapshots occur only at the six original cuts; full RAM hashing is terminal. All worker/parent/IPC/GC work belongs in eventual process CPU measurement.

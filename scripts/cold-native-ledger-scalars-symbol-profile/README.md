# Native execution-window symbol observation: source proposal

This separate diagnostic keeps the qualified ledger-scalar worker's exact
execution timer and while loop, mandatory 166-word return materialization,
compiled revision `85fc1599` and DSO `7de755f0` unchanged. The default backend
remains plain JavaScript. Its owned authority is PENDING; no setup, recorder,
capability command, addon or guest has been executed for this source proposal.
The freely licensed Bochs BIOS supplies the finite checkpoint workload.

A root controller authenticates the fixed ordinary owner, source, Node and perf
images. It drops the worker irreversibly to that owner, preserving the ordinary
HOME and a credential-free environment with exactly two Git trust roots and
system/global Git configuration disabled. Only the newly owned diagnostic
output parent changes ownership. A private socket admits that observed PID and
owner. The recorder attaches disabled; an acknowledged disable precedes worker
release, and enable/disable acknowledgements bracket the unchanged execution
loop. Sampler failures retain the original guest error and independently
attainable terminal proof. Independent final guards retain later evidence even
when an earlier source read fails.

The proposed recorder uses software `cpu-clock` at 99 Hz and DWARF stacks with
an 8192-byte stack capture. It records raw data only; no symbol decoder or guest
replay runs here. `--no-buildid` skips expensive post-record mmap processing and
`--no-buildid-cache` avoids cache writes; exact recorded image hashes and paths
must govern later controlled symbolization. These options and control behavior
are source-reviewed proposals, not installed-tool capability evidence. Their
support must be read from the authenticated effective tool before releasing the
worker. See the [Linux v6.17 perf record documentation](https://github.com/torvalds/linux/blob/v6.17/tools/perf/Documentation/perf-record.txt).

Node hrtime markers and controller monotonic acknowledgements are separate
clock evidence. Until their equivalence to raw event timestamps is demonstrated,
only a conservative ACK interval is reported. Observed existing and later TIDs
do not prove sampling inheritance: actual COMM/FORK/sample PID/TID records,
lost events, unresolved images and stack truncation require independent audit.
No native cost percentage, removable cost, physical clock calibration or speed
qualification follows from this diagnostic.

Proposed bounded PURE controls: seven Node methods (including one wrapper
retaining six Python methods), with manufactured transport/process dependencies
and real temporary receipt writes only. They cover the ten count1 worker seams,
exact held timer/loop, PENDING refusal, ordered ACK/proof/nonce checks, original

failure, independent final guards, owner environment and launch/cleanup paths.

Node 22.23.3 with heap 128 MiB, CPU 10 seconds, wall 30 seconds, file 8 MiB,
core 0, nice increment 10 and six blank hooks. Native/recorder limits remain
worker CPU 60/wall 120/file 16 MiB and profiler CPU 60/file 64 MiB, with bounded
control waits and post-disable collection. This proposal is not a benchmark.

# H4 owned packed scalar candidate

This opt-in, unprofiled derivative authenticates exact ABI2 NAPI a131 source and changes only its scalar callback. Runtime, CABI, memory/PAGE predicates and effects remain unchanged. It is source-only until separately compiled and tested. It emits no BWNP1 records; H2/H3 mapping-call/phase census does not describe this candidate. Whole-candidate timing against H3 includes protocol and bridge/profiler-scaffolding differences.

A new nonwritable, nonconfigurable `packedScalar` data property is installed on the original bounded hot facade only if absent throughout its prototype chain. Installation does not read original methods. The wrapper owns one Uint32Array(3), allocated before guest execution, reusable across calls. It rejects wrong receiver and direct wrapper reentry before host effects or tuple mutation, with finally cleanup.

For each call, the wrapper dynamically reads/invokes nativeTick/quantum/outPort/acknowledgeIrq with original board receiver and original 0/1/3/0 arguments. It validates the operation result first (PIO value getter, others scalar), then dynamically invokes mappingState for non-PIO only. It reads/validates mappingEpoch before boardA20. Numeric validation uses immutable operators; Reflect functions, Object boxing constructor, tuple constructor and error constructors are captured at module initialization before callbacks. Values must be numbers, finite integers in 0..4294967295; negative zero is accepted like original C validation. Property reads preserve the original NAPI ToObject behavior: null/undefined deny, other primitives are freshly boxed for each field lookup; object receivers retain identity. Only after all validations succeed does it fill and return [value,epoch,a20]. No methods/results are cached or operations batched. Host effects preceding rejected metadata remain real and retained.

Native scalar calls packedScalar with internal (op,a,b,c), admits only attached ordinary ArrayBuffer Uint32Array length3, byteOffset0, exact backing byteLength12 and aligned non-null data. It immediately copies12bytes into owned native words before further JavaScript execution. No returned pointer survives the callback. Shared, detached, wrong type/shape/offset/backing reject. The tuple is borrowed for this synchronous callback only; callers must not retain/mutate/detach it. Arbitrary hostile payload controls must be child-contained on the built candidate before qualification.

The loader restricts the existing exact free hot ROM/profile and actual facade; the separate runner preserves current source authentication and bounded regular-file trace protocol. This introduces no new guest capability or compatibility/speed claim.

It retained 165 CPU-clock leaf samples: 136 on the worker main thread and 29 on four background threads. Seven existing worker TIDs were attached; two had no retained leaf samples. DSO bins were Node 104, native addon 14, libc 32, JIT 11, libstdc++ 1 and kernel 3. Of these leaves, 47 had unknown symbols. Native leaves include `fusion_u32` and `bw_slice_write`; resolved Node leaves include V8 string, object and backing-store operations. These counts motivate source analysis of callback/property and allocation work; they do not identify removable CPU cost.

The native mapping appears before the first retained CPU-clock sample. No explicit LOST record was printed, which does not prove zero loss. Leaf decoding does not qualify callchain unwind. Kernel, unmatched libraries and JIT frames remain unresolved. Raw sample times span 57.833848384–59.200098121 seconds in the recording clock. The source still labels Node/perf clock equivalence unproven; control ACK bounds are conservative observer evidence, not execution-only clipping. No sample percentages, native CPU share or performance gate are inferred. The header's zero sample-duration fields do not describe the nonempty decoded tape.

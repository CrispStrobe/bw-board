# Predeclared first-refusal context diagnostic for the 386 trace grammar

The [form-resolved 60M result](I80386-FORM-RESOLVED-ADMISSION-RESULT.md) admitted 21,057,233 ordinary retired ordinals but only 3,023,405 in disjoint runs of at least eight. A total of 22,906,374 first refusals were `unsupported-opcode` and 1,273,443 were `unsupported-group-extension`. The existing report does not connect those reasons to ModR/M extension or neighboring run length. This opt-in diagnostic adds that cross-tab without changing guest execution or the earlier admission rules.

`AT_FORM_REFUSAL_CONTEXT=1` selects ordinary single-step execution with form admission plus a first-refusal context observer. It is mutually exclusive with `AT_FORM_RESOLVED_ADMISSION=1`, the broad observer variant and execution dispatchers. Each eligible refused ordinal is recorded once under its **first refusal reason** and the observed fetched-byte shape: primary opcode (or `0F` secondary), exact prefix sequence, operand/address width, declared ModR/M mod `/reg` rm, 16/32-bit EA/SIB/displacement shape, and actual board-observed read/write/port activity. For an opcode without a declared ModR/M syntax, `parseStatus` says so; the diagnostic never guesses missing fields. Observed memory activity can include implicit stack or translation accesses and is **not** proof of a reusable EA micro-op. No instruction bytes, addresses, media identifiers or guest text enter the public cross-tab.

For each refusal, the histogram stores the admitted run immediately before it and the immediately following admitted run, each capped at the existing 64-step run budget. The following length is zero when another refusal, page/mode/CS/identity change, host write, input, interrupt, REP iteration, no-retirement, abort or other existing cut intervenes. A safety refusal or refused I/O side effect is also a zero-following side exit. `bridgeAtLeast4` and `bridgeAtLeast8` count refusals with *both* adjacent runs at least that long. These are local boundary contexts, not disjoint potential-trace ordinals: adjacent bridges can overlap and adding an instruction can change event, memory and code identity behavior. The ordinary CPU remains the syntax and semantic oracle.

A future pinned 60M Windows pair must use the same committed board revision and full source-hash map in both arms, the same verified BIOS/VGA/HDD/input pins, an ordinary observer-off baseline, and a serial `AT_FORM_REFUSAL_CONTEXT=1` arm. Reduce with `node scripts/summarize-i80386-form-resolved-admission.mjs observed.json baseline.json --require-first-refusal-context`. That reducer verifies source blobs, selected guest/input parity, typed partitions and context histograms before a media-neutral receipt can be published. Do not use observed-arm runtime as speed data. No heavy run accompanies this change.

The next **measurement choice is predeclared before inspecting that pair**. Candidate A is an *execution-neutral ordered replay* of the existing grammar plus `80/81/83` `/0` ADD, `/1` OR, `/4` AND, `/5` SUB and `/6` XOR, distinguishing register and RAM forms and preserving every existing safety/event cut. Sum `bridgeAtLeast4` only for records whose first reason is `unsupported-group-extension`, whose opcode is `80`, `81` or `83`, and whose `modrm.reg` is 0, 1, 4, 5 or 6. Select Candidate A only if that sum reaches **250,000 overall and 100,000 in protected16+VM86**. These thresholds are a prioritization screen, not estimated extra run coverage. If either fails, do not build that replay; inspect the ranked stack (`50–5F`), direct call/return (`E8`, `C2/C3/CA/CB`), segment (`8C/8E`) and mixed `FF` refusal contexts, then predeclare a different typed grammar after its fault, stack, segment and control-state contracts are proved. If Candidate A qualifies, the ordered replay must recompute disjoint ≥8-run ordinals under the expanded grammar; the same 15M overall / 5M protected16+VM86 opportunity threshold remains the minimum before any Windows performance executor is considered. No aggregate refusal histogram by itself can pass that threshold.

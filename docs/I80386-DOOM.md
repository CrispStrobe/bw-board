# Original Doom 1.9 on the experimental 386 AT

The original shareware executable and IWAD boot through IBM AT firmware,
SeaVGABIOS and FreeDOS. The [combined gameplay receipt](receipts/2026-09-20-386-doom-combined-gameplay.json)
records real keyboard input entering E1M1, moving forward and firing the pistol;
audited frames show the changed viewpoint, muzzle flash and ammo 50→48.

The [short-demo receipt](receipts/2026-09-20-386-doom-short-demo.json) separately
records loading an owned 110-byte ASTRA.LMP file through DOS, rendering E1M1,
completing 24 gametics and returning to the DOS prompt. The original executable
and WAD hashes are unchanged. Its 1464 realtics are functional-clock output,
not a physical-hardware performance measurement. Four attack commands are
part of the recording; the retained demo frame shows ammo 50, so this frame
alone does not prove firing. The separate keyboard replay does.

Build the reproducible input with Node22:

```sh
node scripts/build-i80386-doom-short-demo.mjs /path/to/DOOM.EXE /path/to/DOOM1.WAD /tmp/short-demo.img
```

Select that image with `AT_HDD_IMAGE`, the receipt's BIOS/VGA/FreeDOS inputs,
`AT_POST_STEPS=350000000`, and a `FREEDOS_COMMAND_SCRIPT` containing the actual
carriage-return-separated commands `c:` and `doom -timedemo astra -nosound`.
Run `scripts/run-i80386-freedos-doom.mjs` from an immutable checkout and retain
its JSON report. The runner supplies the installer's initial decline itself;
do not prefix another `n` command. Do not enable `DOOM_GAME_KEYS` for this demo.

The acceptance helper checks the recorded revision, image/game hashes,
command, completion line, final DOS prompt, absence of refusal/shutdown and
the exact audited frame hashes. It qualifies this historical fixed run;
changed source/configuration needs a fresh replay and audited receipt before
updating expected revisions or hashes. With the original raw report available,
set `ASTRA_DOOM_SHORT_REPORT` when running its focused acceptance test.

The original full demo1 run with drawing disabled exhausted 500M instructions
without completion. Sound, save/load, networking, every level and general
Doom/386 compatibility remain outside these bounded milestones.

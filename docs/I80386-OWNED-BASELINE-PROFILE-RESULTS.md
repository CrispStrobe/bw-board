# Owned baseline Inspector results

One hosted Inspector diagnostic completed on the fixed IN8 baseline. Its 111 execution-window samples partition into 78 JavaScript frames, 28 native shared-invoke alias frames, four garbage-collector frames, and one program frame. The largest individual leaves were `close` (28 samples), `resume` (15), and `clockTransfer` (10). These are qualitative samples from one JavaScript isolate, not percentages of process CPU.

The `close` leaf occurs under the source-owned resume callsite: the addon shares an invocation implementation across exports. It does not establish that closing the machine consumed this time, nor separate Bochs execution from NAPI snapshot construction. Inclusive function and stack ranks are provided separately; they overlap, and recursive instances of one function identity receive at most one credit per selected sample. The complete 112-sample raw profile, all selected indices, timestamp tape, phase markers, alignment control and source locations remain in the receipt archive.

The unchanged scheduler produced a full native snapshot at each of 445 resumes. The stored reset, final and six-cut snapshots match the reference in all 166 native state words, with six board checkpoints, device and physical callback counters, and raw/canonical RAM checks. Source-backed comparison retains eight exact CPU fields and the two documented reset-profile differences. Artifact admission passed 1,463 independent checks; read-only analysis passed 102 independent checks. The observed execution window was 124,005,591 ns and process CPU was 203,994 µs. This single instrumented observation is not a throughput gate, speed result, or an all-thread CPU attribution.

The final counters were 9,211 clock transfers, 8,733 commits and 201,390 logical clock words, with 4,235 reads, 4,205 writes and 26 execute-page callbacks. The 201,390 logical words are not 201,390 NAPI crossings. The rejected bulk clock candidate remains rejected; this diagnostic changes no production runtime or default.

Official artifact 11237781906 has ZIP SHA-256 `09ceafcd30f8deae85df8cf96ac10fca9e98fc4362ed8ab12049ee1ad4c0c544`. Profiling derivatives have their own exact inverse and diagnostic identity; the frozen 103-file source is not relabelled as instrumented source.

A next source-only candidate is to specialize the private provider's per-word dispatch into captured zero-argument N and one-argument Q calls, avoiding the current temporary argument arrays and `Reflect.apply` on this internal loop. It would retain the complete ordered preflight, every original N/Q board method and guard, queries, deadlines, CAPON events and ordinary full snapshot arrays. This differs from aggregating clock effects or specializing board `_call`, both previously rejected experiments. The stacks justify investigating this boundary but predict no gain. Before native execution it needs differential lifecycle, exception-order, malformed-tape, deadline, mapping and exact event controls, plus source/compiled identity review. No candidate has been implemented or qualified here.

# Factory-owned source-only board clock replay

External licensed-guest notes and historical context are retained in the [private documentation archive](https://github.com/CrispStrobe/brickwright-firmware-private/tree/master/public-documentation-archive/2026-10-04). Public examples and instructions use freely licensed or freeware software.

Implemented: a factory with no caller board/config/ROM/hooks/options creates a private actual HotDirectBoardFacade in a pristine Worker realm. The returned frozen object contains only serialized snapshots and replay/inspect/close/abort functions. No Worker, board, machine, chip, callback table, ROM, retained typed array or shared backing leaves its closure. The worker derives the exact existing free ROM and board configuration internally. It does not import an addon or step a CPU. Generic H4 files/prototypes and dynamic callback/getter behavior remain unchanged.

The public protocol accepts primitive JSON strings only. No Proxy/accessor detector or general hostile-object sandbox is claimed; objects/functions/buffers are rejected by typeof before access. Parsed messages are bounded in bytes/nodes/depth. Resume preflight checks the entire operation stream, independent N/Q caps/order, six-cycle Q ledger, callback debt and mapping chronology, fields and admitted physical spans before effects. Device-derived entry/horizon and actual operation-result mismatches are separately checked against the real board and quarantine the worker if they fail; preflight is not an atomic device transaction or rollback claim.

Each parent message contains one whole replay resume. Inside that realm all ordered N/Q groups and memory/PAGE/PIO/ACK observers are synchronous local calls, with no per-callback/clock IPC. Replay groups expand every historical logical row in original order. N increments independently of Q, including fault N without Q and partial REP Q without N. Q kind is retained; clock debt/due uses successful work, never a native deadline conversion. An admitted PIO cut settles preceding debt and rearms the actual device horizon before current instruction Q; clock groups end before every observer and resume return. Counters describing replay groups are not native crossing counts or legal execution span counts.

A closed synchronous worker lease and parent busy state reject concurrent resume/inspect/close immediately. No caller hook executes during that lease. Inspect returns serialized copies only. Malformed semantic replay fails closed and cannot be inspected or resumed afterward. Close requires a supplied historically authenticated final zero-work HLT return witness plus fixed final N100684/Q100682 and marker RPGH001; board state does not independently prove CPU HLT. Resumes after that terminal witness are denied. Close performs actual terminal device settlement; explicit abort abandons proof and terminates without exposing state. Startup and every request have ten-second deadlines, and error/exit/timer cleanup rejects pending work. Raw worker bytes are checked at startup; the complete source/import closure and artifact hashes must be pinned by the source-bound proof receipt before use.

Captured Worker/EventEmitter dispatch methods and private own method shadows prevent direct later prototype dispatch replacement from exposing the Worker receiver. Mutated parent Worker infrastructure is denied before construction. This is not a sandbox against arbitrary modification of Node internals, preload machinery, filesystem/source code, inspector or process globals. Parent generic board/machine/chip/config mutations do not cross the independent realm. Worker execArgv is empty and NODE_OPTIONS is empty; no caller worker path or resource options exist.

The historical replay gate requires authenticated full bf12 journal, all resume/observer fences and canonical native trace reference. It independently reproduces every real-board logical callback row, six selected actual board checkpoints, settled board/PIT/PIC state and entire RAM. It does not execute or independently reproduce native CPU instructions/canonical CPU rows; those are prior authenticated reference evidence. No speed, native admission, full AT, broader guest/broader game, native CLI/GUI or legal batching span claim follows.

Future ABI: load the authenticated addon and execute CPU inside this SAME owned worker. Memory/PAGE/PIO/ACK/clock flushes must remain local synchronous callbacks; parent IPC is only resume/input/snapshot boundaries. Static pending ordered N=1/Qkind tape and local independent ledgers must survive Bochs longjmp, preserve logical traces and flush before faults/IRQ/HLT/inspect/return. This native ABI is not implemented here and requires separate source/runtime/canonical parity and unprofiled CPU validation gates.

# Ordinary cold-BIOS reference preparation

`createColdBiosJavascriptOracle()` accepts no caller arguments, configuration, machine or hooks. It owns the fixed ordinary JS machine, exact unmodified BIOS, controller12/32 timing and no unsolicited keyboard/mouse responses. `step()` executes one ordinary completion or one REP element, and returns zero Q only when already before F000:E16. `position()` is cheap; `checkpoint()` produces detached raw architectural CPU and full board state only when requested. `records(start)` copies only a requested journal tail; `settleCheckpoint()` catches up real device clocks and hashes whole raw RAM. Native N/attempt/completion counters are not assigned by this oracle.

`captureColdReference(visitor?)` retains fifteen ordered named CPU/board cuts, actual four-site REP entry/exit registers and all400 element progress/store effects, complete ordered actual PIO, observed code-page mappings and raw final RAM SHA. It does not retain a316k full snapshot array or claim native hidden-word comparison. The optional synchronous per-step visitor can request a detached checkpoint for future nativeQdelta0/1 pairing; default capture never serializes a full board per step. Structural/protocol validation checks caps, cuts, REP records, exact AA55AB00 interleaving and PIO ownership. It does not authenticate caller-supplied output.

The explicit opt-in baseline test authenticates frozen current/Git source before and after execution, plus actual Node bytes. Its inventory includes this reference/test/note, package metadata, the complete relative CPU/machine/config/device/helper JS import closure, and explicitly read BIOS/license assets. Unexecuted native derivatives, unrelated docs and other lanes are excluded; the external bounded harness is separately pinned. A capture report by itself is ordinary JS data; only the actual before/after receipt establishes source authentication. The older316562-step exploratory census is not that authenticated baseline. No complete cold baseline has run at preparation. Seven pure source controls pass; after adding the standalone REP Q cap, the two relevant REP/cut tests also pass. All48 source and Node pins remain unchanged within each bounded capture. The initial EAX mutation was strengthened to retain uint32 values; one redundant unchanged pure run is retained without a new coverage claim. [Raw source receipts](../../docs/receipts/native-cold-bios-reference-source-20261003/index.json) preserve the executed scope-note bytes before this evidence paragraph was added.

Normal CI runs seven pure refusal tests; it skips the full cold capture unless a reviewed bounded harness supplies `BW_COLD_REFERENCE_OUTPUT`. Source controls use clearly labeled synthetic structural fixtures, not invented baseline measurements. One actual source+JS baseline child is proposed under CPU15/wall30/heap128/nice10/file8MiB/core0 and six blank hook variables, only after source freeze/review. Failures retain stdout/stderr/exit and baseline receipt; there is no automatic retry.

The native comparator remains a separate slice. Raw reset EDX/CR0/descriptor/debug profiles are retained; legitimate cold-BIOS writes can eliminate or store their differences. The tiny AA/AB fixture's persistent reset literals, N=Q=index and HLT terminal must not be copied. Whole RAM is never pre-normalized. Future execution must stop before E16 without HLT/marker injection, preserve actual asserted PIC line, and deny delivery while IF remains clear. No native addon, build, guest or speed qualification is performed here.
